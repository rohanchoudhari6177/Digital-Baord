# Digital Notice Board (Simple Version)

A simple, responsive notice board made with **HTML, CSS and JavaScript** only.

## Run it
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Safari, Edge or Firefox.
3. No installation, Java backend, database or server is required.

## Working features
- Search notices by title, description or category
- Filter by category and priority
- View important notices and upcoming deadlines
- Save/bookmark notices
- Add a notice through the “Add notice” form
- Saves notices and bookmarks in the browser using `localStorage`
- Responsive layout for mobile and desktop

## Edit the sample notices
Open `script.js` and edit the `initialNotices` list near the top.

## Important note
This is a simple frontend project. Notices are stored in the current browser, not in a shared online database. If you want every student to see the same notices from different devices, a backend/database will be needed later.
